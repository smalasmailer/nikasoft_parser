# NikaSoft Parser + Бот
Скрипт для парсинга расписания Ника-Софт.

## Использование index.py:
`python3 index.py --args `<br>
Аргументы:<br>
--file - локальный JS-файл с расписанием <br>
--url - ссылка на JS-файл с расписанием <br>
--class - класс (например, 5а) <br>
--date - дата в формате ДД.ММ.ГГГГ (например, 16.02.2026) <br>

## Использование бота (bot.py)
`python3 bot.py`<br>
Перед запуском бота нужно задать параметры (найти их можно по комментарию PARAMS / ПАРАМЕТРЫ):<br>
TOKEN - токен бота из BotFather<br>
JS_URL - URL-путь к JS-файлу.<br>
JS_FILE - будущее название файла (при запуске бота файл скачивается с таким названием, какое указано в этом параметре)<br>
